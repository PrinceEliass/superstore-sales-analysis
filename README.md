# Superstore Sales Performance Dashboard

**Power BI + SQL** -analysis of a fictional Superstore retail chain (Kaggle dataset).

![Dashboard Overview](dashboard-page1.png)

## Project Overview

This project presents a comprehensive sales analysis of over **9,900 orders** from 2014 to 2017. The objective was to transform raw transactional data into actionable business insights through interactive visualizations and SQL analysis.

## Key Insights

- Technology category generates the highest profit.
- Consumer segment represents over **50%** of total sales.
- Sales show clear seasonality, with Q4 (November–December) being the strongest period.
- Discounts have a significant negative impact on profitability.

## Tools & Technologies

- **Power BI Desktop** – Data visualization, DAX measures, Power Query
- **SQL** – Data querying and business analysis
- **DAX** – Custom KPIs and calculations (Profit Margin, trends, etc.)
- **Kaggle Dataset** – Sample Superstore
